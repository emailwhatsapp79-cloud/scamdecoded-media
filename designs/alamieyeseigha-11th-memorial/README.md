# 11th Memorial Anniversary — Late Chief D.S.P Alamieyeseigha

Final poster: `alamieyeseigha-11th-memorial-1080x1350.jpg` (social) and `-2160x2700.jpg` (print/hi-res).

## Layers (`source/`)
- `portrait_hb.png` — half-body press photo (BellaNaija, 2016): Real-ESRGAN x4 upscale, face restored with CodeFormer (fidelity 0.7, blended 80/20 with the original), background and bystanders removed
- `statue_fade.png` — statue photo supplied by the client, background and plinth removed, bottom faded
- `bg.jpg` — "Mekong bank dwellings at golden hour, Don Khon" (Wikimedia Commons, free licence), mirrored so the river sits on the right, colour-graded warm
- `flag.png` — generated waving flag in Ijaw colours (blue / red / green)
- `poster.html` — layout, gold text and ribbon; render at 1080x1350 with deviceScaleFactor 2

## Editing in Canva
- `alamieyeseigha-memorial-canva.pptx` — import into Canva (Create a design → Import file). Every element is a separate, movable image on a 1080x1350 page.
- `alamieyeseigha-memorial-layers.zip` / `canva-layers/` — the same transparent PNG layers (2x resolution) to upload and arrange by hand.
